# Entregáveis do concurso

Esta pasta organiza os materiais de submissão que dependem de confirmação
externa. Nenhuma URL de produção, captura, resultado de smoke test, tag, release
ou comprovante de inscrição foi registrado aqui neste momento.

| Artefato | Finalidade | Estado |
|---|---|---|
| `DESCRICAO_SUBMISSAO.md` | Texto-base para adaptar aos campos do formulário | Pendente de revisão e preenchimento externo |
| `ROTEIRO_DEMO.md` | Roteiro para demonstração gravada ou ao vivo | Pendente de confirmar ambiente e casos exibidos |
| `SMOKE_TEST_PRODUCAO.md` | Checklist de validação da implantação | Pendente de URL, execução e evidências |
| `capturas/` | Local para imagens e vídeos aprovados | Vazio intencionalmente; capturas pendentes |

Armazene somente artefatos aprovados, sem dados pessoais, credenciais, tokens ou
dados brutos. Ao adicionar uma evidência externa, informe data, responsável,
origem e referência verificável.
